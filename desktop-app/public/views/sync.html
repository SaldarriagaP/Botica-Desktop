Sincronización con el sistema central

Estado
¿Cómo funciona?
  1. Si se va el internet o la luz, sigue vendiendo aquí: cada venta queda guardada en esta computadora con su comprobante.
  2. La terminal intenta conectarse con el central automáticamente cada minuto.
  3. Cuando vuelve la conexión, las ventas pendientes se suben solas y se actualizan los precios.
  4. También puedes forzarlo con Sincronizar ahora.
